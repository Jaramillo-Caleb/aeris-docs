# Aeris

Videojuego de rompecabezas inspirado en Tetris, en el que el jugador controla las piezas con movimientos de una mano en el aire, capturados por una cámara convencional y procesados con visión por computadora. Sin teclado, ratón ni controles físicos.

Este repositorio contiene la **documentación del proyecto**, organizada por etapas del ciclo del proyecto de inversión.

## Estado actual

- **Etapa:** Preinversión
- **Nivel:** Idea
- **Versión del documento de idea:** 0.1 (12/10/2026)
